# Junkai Kang · Academic homepage

A simple academic homepage based on the layout of the Minimal Light Jekyll theme: profile information on the left and evidence-led academic content on the right, with a separate photo page. The homepage includes a selected publication, structured research-project summaries, education, honors, and service.

## Preview locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a public repository named `threek-1.github.io`.
2. Copy this folder’s contents to the repository root.
3. Commit and push to `main`.
4. Enable GitHub Pages from the `main` branch and `/ (root)`.

The website will be available at `https://threek-1.github.io/`.
